# ADR-001 — Adoção de Node.js com TypeScript

- **Situação:** aceita
- **Data:** 2026-10-25
- **Participantes:** Cesar Henrique, João Gabriel, Pedro Domingues e Vitor Hugo

## Contexto

O projeto Connexa precisa de uma stack tecnológica que permita desenvolver uma aplicação organizada, sustentável e de fácil manutenção. A solução deve facilitar a colaboração entre os integrantes da equipe, reduzir erros durante o desenvolvimento e permitir a evolução do sistema ao longo do projeto.

## Decisão

Adotar Node.js como ambiente de execução do JavaScript no back-end e TypeScript como linguagem de desenvolvimento, aproveitando a tipagem estática para melhorar a identificação de erros e a organização do código.

## Alternativas consideradas

| Alternativa | Por que não foi escolhida |
|---|---|
| .NET com React | A equipe optou por Node.js com TypeScript como stack principal para o desenvolvimento do projeto, priorizando a adoção de uma única linguagem no back-end e o aproveitamento dos conhecimentos da equipe. |
| Java com Spring Boot | Exigiria adotar outro ecossistema de desenvolvimento, sem aproveitar diretamente a stack escolhida pela equipe. |

## Consequências

- **Positivas:** maior segurança na manipulação de tipos, melhor suporte à autocompletação e manutenção mais organizada do código.
- **Negativas:** necessidade de configurar a compilação ou execução do TypeScript e aprender a trabalhar com tipos, interfaces e configurações específicas.
- **Como verificar:** revisar os pull requests para garantir que o código siga os padrões definidos, que os arquivos TypeScript sejam verificados pelo compilador e que os testes e checks do CI sejam aprovados.
